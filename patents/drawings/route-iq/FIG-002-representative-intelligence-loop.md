# Figure 2 - Representative Intelligence Loop

## Figure Title

Representative Intelligence Loop

## Purpose

Show the recurring loop by which Route IQ converts representative actions into evidence, updates intelligence layers, recalculates probabilities, generates recommendations, and returns adaptive guidance to the representative.

## Components

- Representative.
- Representative action.
- Evidence collection.
- Learning engine.
- Representative learning.
- Territory learning.
- Customer learning.
- Outcome learning.
- Probability recalculation.
- Recommendation generation.
- Representative response.

## Relationships

- Representative action produces evidence.
- Evidence collection supplies structured records to the learning engine.
- The learning engine updates representative, territory, customer, and outcome learning states.
- Updated learning states feed probability recalculation.
- Probability recalculation feeds recommendation generation.
- Recommendation generation returns guidance to the representative.
- The representative response becomes a new action and restarts the loop.

## Narrative Description

Figure 2 depicts the continuous Route IQ intelligence loop. The representative begins by taking an action, such as reviewing a customer, visiting a customer, recording a note, accepting a recommendation, rejecting a recommendation, or creating a follow-up. The system collects evidence from that action and provides it to the learning engine. The learning engine updates one or more learning categories, including representative learning, territory learning, customer learning, and outcome learning. The updated learning state is used by the probability engine to recalculate the likelihood of future outcomes. The recommendation engine uses those recalculated probabilities to generate new guidance. The representative receives the guidance, takes another action, and the cycle continues.
