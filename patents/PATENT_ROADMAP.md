# Patent Preparation Roadmap

Initialized: 2026-07-09

Purpose: Track preparation work for future attorney review. This roadmap does not determine filing strategy or patentability.

## Phase 1 - Foundation

Status: Initialized

Tasks:

- Create canonical patent preparation subsystem.
- Create master disclosure package.
- Create invention register.
- Create drawing register.
- Create copyright, trade secret, and trademark registers.
- Create subject-area workspaces.

## Phase 2 - Evidence Collection

Status: In progress

Tasks:

- Identify source repository files for each invention candidate. Route IQ v1 evidence register created.
- Gather product screenshots and workflow artifacts. Founder confirmation required.
- Gather existing reports and design documents. Initial Route IQ support materials indexed.
- Record inventor interviews.
- Record conception and reduction-to-practice timelines.
- Record known public disclosures.

Route IQ evidence register:

- `patents/route-iq/INVENTION_EVIDENCE_REGISTER.md`

Route IQ evidence gaps:

- Founder must confirm first conception date, first architecture discussion, first working prototype, public disclosures, private disclosures, customer/prospect discussions, attorney consultation history, and screenshot/UI evidence.

## Phase 3 - Technical Disclosure Expansion

Status: Planned

Tasks:

- Expand each invention candidate into a full technical disclosure.
- Add alternative implementations.
- Add embodiments and future embodiments.
- Add system architecture diagrams.
- Add workflow diagrams.
- Add data-flow diagrams.
- Add implementation examples.

## Phase 4 - Attorney Review Package

Status: Planned

Tasks:

- Prepare attorney-ready disclosure packet.
- Provide invention register.
- Provide drawing register.
- Provide source-material index. Route IQ initial evidence register created.
- Provide public-disclosure timeline. Founder confirmation required.
- Provide unresolved technical questions.

## Phase 5 - Portfolio Support

Status: Planned

Tasks:

- Track follow-on invention disclosures.
- Track continuation, continuation-in-part, or divisional support materials if counsel requests them.
- Track copyright deposits or registration support materials if counsel requests them.
- Track trademark use evidence if counsel requests it.
- Track trade secret handling records.

## Attorney Review Dependencies

- Counsel must determine patentability, claim scope, filing strategy, ownership questions, public-disclosure implications, and formal application language.
- This subsystem provides technical facts, source evidence, diagrams, timelines, and invention-support materials.
