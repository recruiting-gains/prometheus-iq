# Copyright Register

Initialized: 2026-07-09

Purpose: Track Prometheus copyright-support materials for attorney review and future registration support.

This register does not file copyright registrations and does not make legal conclusions about ownership or registrability.

## Register Fields

Each record should include:

- Identifier.
- Work title.
- Work type.
- Author or contributor notes.
- Creation date.
- Publication or disclosure status.
- Repository or storage location.
- Derivative-work notes.
- Third-party dependency notes.
- Attorney-review questions.

## Initial Categories
