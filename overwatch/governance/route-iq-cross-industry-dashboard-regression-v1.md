# Route IQ Cross-Industry Dashboard Regression Governance v1

Route IQ now uses one configuration-driven Dashboard across Fitness Founder research and a synthetic general outside-sales profile. Business identities do not select reusable application code.

The authoritative flow is:

`authenticated session -> Administration configuration -> Data manifest -> normalized availability -> Intelligence eligibility -> Infrastructure projection -> Dashboard`

Production may not use embedded catalogs, demo fallback, cross-workspace records, or caller-selected identity. The required runtime assets are `workspaceConfiguration`, `businessManifestRegistry`, `businessRoster`, and `businessHours`.

Availability expires within 24 hours. Immediate stops require fresh verified-open evidence or a verified current access window. Closed, stale, unavailable, invalid, provider-failure, and unverified appointment states fail closed.

Operating hours and estimated visit duration are separate data and presentation fields.

The release gate scans current tracked and untracked repository files, deploy mirrors, configuration, manifests, pools, contracts, and runtime source. A retired business identity may exist only in the one nondeployable negative regression test.

Production deployment, scheduler activation, provider credentials, cache purge, migration, collection, cohorts, recommendation influence, and Anthony mapping remain separately Founder-gated.
