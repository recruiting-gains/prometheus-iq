# Route IQ Controlled Paid-Customer Onboarding Rehearsal v1

Owner: Prometheus Administration

The controlled rehearsal admits one clearly fictional company configuration for an
authenticated, ephemeral production-memory exercise. It composes the existing paid-customer
onboarding contract and security boundaries without activating a customer or persisting a
customer record.

The definition contains two fictional locations, one synthetic owner-manager, two synthetic
representatives, explicit operating-hour evidence, and a simulated price plan. Live Stripe
identities, payment methods, subscriptions, invoices, invitations, provider calls, scheduling,
collection, cohorts, recommendation influence, and customer activation are prohibited.

The only permitted lifecycle outcome is `DRAFT` through a recorded validation failure to
`VALIDATED`. `VALIDATED` remains non-activating. Runtime orchestration must use a new in-memory
store for each authenticated GET, remove every rehearsal record before returning, and prove the
store is empty. Any uncertain identity, scope, role, lifecycle, hours, billing, or cleanup state
fails closed.

This definition is synthetic test authority only. It is not a customer record, CRM record,
provider input, invitation source, billing authorization, or public customer claim.
