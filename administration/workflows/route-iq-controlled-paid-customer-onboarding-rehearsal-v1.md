# Route IQ Controlled Paid-Customer Onboarding Rehearsal v1

Owner: Prometheus Administration

The controlled rehearsal admits one fixed, clearly fictional company definition for an
authenticated, ephemeral production-memory exercise. No caller-provided company, workspace,
location, address, industry, terminology, role, schedule, Dashboard, CRM, provenance, billing,
or lifecycle substitution may materialize. The canonical definition is the complete authority.

The reusable security-services template remains unauthorized for general production use. This
fixture grants only a narrow Administration authorization to derive the canonical rehearsal in
fresh process memory during the authenticated rehearsal request. Durable production use,
production customer use, persistence, CRM mutation, invitations, provider calls, scheduling,
recommendation influence, live billing, and customer activation remain prohibited.

The definition contains two fictional locations, one synthetic owner-manager bound to the exact
manager role, and two synthetic representatives bound to the exact representative role. Each
location carries complete verified-business evidence: immutable scope, verified identity and
address, actual weekly schedule and access window, provider and provenance, operating status,
freshness interval, duplicate and conflict resolution, target-profile match, evidence quality,
and a safe recommendation reason. The evaluation instant must be inside the verified interval,
which may never exceed 24 hours. The open location must satisfy the existing Intelligence
admission contract in validation-only mode; the closed location must fail current-stop admission.

The only permitted lifecycle exercise is canonical `DRAFT`, an explicitly controlled invalid
location-scope attempt that fails closed, recovery from recorded `VALIDATION_FAILED`, and
`VALIDATED`. `VALIDATED` remains non-activating. Runtime orchestration must use a new in-memory
store for each authenticated GET, remove every rehearsal record before returning, and prove the
store is empty. Any uncertain identity, scope, role, lifecycle, hours, billing, or cleanup state
fails closed.

This definition is synthetic rehearsal authority only. It is not a customer record, CRM record,
provider input, invitation source, billing authorization, public customer claim, or reusable
production seed.
