## Before Access

- Founder approved tester.
- Agreement path selected.
- NDA/agreement status recorded.
- Permission role selected.
- Intended beta URL selected.
- Device/browser recorded or scheduled.
- Infrastructure access request prepared.

## Access Verification

- Tester can open the protected beta URL.
- Tester uses Rep mode only.
- Owner/admin controls are not visible.
- Current release/build is visible or otherwise verified.
- Directions links open correctly.
- Log Result workflow works.
- Copy Today Summary or Export Today Report is understood.

## Training

- Tester understands the purpose of the beta.
- Tester understands GPS verification is visit-based, not continuous tracking.
- Tester understands what to log after field activity.
- Tester understands what data not to enter.
- Tester knows how to report bugs.
- Tester knows how to submit feature requests.
- Tester knows what to do if Cloudflare One-Time PIN fails.
