# Prometheus IQ Competitive Differentiation

Primary source document:

## Executive Use

Use this document when explaining why Prometheus IQ exists alongside Salesforce, HubSpot, SPOTIO, and route-planning tools.

## Core Positioning

Prometheus IQ is not trying to replace CRM systems. It is positioned as field-sales intelligence for the work that happens before and during outside-sales activity.

## Strongest Differentiator

Verified field-sales intelligence:

- Route Intelligence.
- GPS visit verification.
- Field outcome logging.
- Manager visibility.
- Decision-making based on measurable field activity.
