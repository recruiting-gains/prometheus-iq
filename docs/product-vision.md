# Prometheus IQ Product Vision

## What Prometheus IQ Is

Prometheus IQ is the first product from Prometheus. It is a field sales command center that helps outside salespeople decide where to go, track what happened, measure which locations produce sales, and improve routes over time.

The first version is built for Cruz selling Fitness Connection gym memberships outside the gym. The long-term version should work for any business with outside salespeople, door-to-door reps, local outreach teams, canvassers, membership sales teams, appointment setters, or field promoters.

## Core Promise

Prometheus IQ helps outside salespeople sell more while wasting less time and gas.

It should answer:

- Where should I go today?
- Which locations actually produce sales?
- What time windows work best?
- Which route saves gas and avoids random driving?
- Which locations are worth revisiting?
- Which categories fit this salesperson's strengths?
- What is the fastest path to today's sales goal?

## Current Focus

- Hit 10 units per day.

## What Prometheus Does Now

- Shows a daily scoreboard toward a 10-unit goal.
- Tracks units today, units needed, visits today, conversations, and leads.
- Calculates a fastest path to 10 based on logged averages.
- Builds a ranked route list from saved places.
- Pushes places already visited today down the route list.
- Tracks production by location.
- Tracks production by category.
- Tracks production by time window.
- Color-codes places:
  - Green: produced units
  - Yellow: produced leads
  - Red: visited with no production
  - Blue: not visited yet
- Saves real places and map-search targets near the gym.
- Generates rotating daily map searches for new places and replaces saved suggestions with unused discovery ideas over time.
- Tracks permission value:
  - Allowed table
  - Allowed flyers/cards
  - Allowed shift change
  - Allowed staff talk
  - Allowed resident email
  - Come back later
  - No
- Tracks whether a place can be revisited.
- Separates same-day units from later units.
- Stores data locally in the browser.
- Supports backup export and import.
- Has install/offline app files for a more app-like experience.

## What Prometheus Should Become

Prometheus should become a learning sales route engine.

As the salesperson logs more visits and results, the app should learn:

- Which location categories the salesperson performs best at.
- Which locations waste time.
- Which areas produce the highest units per visit.
- Which time windows produce the best results.
- Which permission types lead to more sales.
- Which routes save time and gas.
- Whether the salesperson is better with apartments, restaurants, auto shops, salons, events, warehouses, retail centers, or other categories.

The app should not just record history. It should use history to recommend better action.

## 3-Month Build Direction

### Month 1: Personal Proof

Goal: prove Prometheus helps one salesperson produce better outside results.

Build and refine:

- Better daily route planning.
- Cleaner visit logging.
- Better stats.
- Gas-saving route notes.
- Weekly performance summaries.
- Category performance.
- Time-window performance.
- Location revisit logic.
- Backup and import reliability.

Success proof:

- Real logs from daily field work.
- Better understanding of where units come from.
- Less random driving.
- Clear top-producing locations and categories.

### Month 2: Learning Engine

Goal: make Prometheus start learning from the salesperson.

Build and refine:

- Strength and weakness profile.
- Smart recommendations based on prior results.
- Suggested daily route based on units per visit, distance, time window, and revisit value.
- Gas/time efficiency scoring.
- Location fatigue detection.
- Category confidence scoring.
- Weekly coaching summary focused on production data, not scripts.

Success proof:

- Prometheus can explain why it recommends certain places.
- The route gets smarter as more data is entered.
- The salesperson can see where they are strong and where they waste time.

## Subscription Product Idea

Each business should be able to configure:

- Sales goal
- Unit type
- Location categories
- Route radius
- Sales territory
- Required visit fields
- Permission types
- Team members
- Reports
- Industry-specific dashboard language

Example business-specific versions:

- Gym: memberships, tours, leads, resident events, local businesses.
- Roofing: inspections, doors knocked, claims, booked estimates.
- Solar: consultations, qualified homes, appointments, signed deals.
- Pest control: doors knocked, callbacks, recurring plans.
- Real estate: open house leads, neighborhoods, appointments.

## Main Differentiator

Most sales tools track leads after they are created.

Prometheus helps outside salespeople decide where to create the leads in the first place.

That is the difference:

- Not just CRM.
- Not just maps.
- Not just route planning.
- Not just notes.

Prometheus combines route planning, production tracking, location intelligence, gas-saving decisions, and salesperson-specific learning.

## Product Rule

Every feature should help with at least one of these:

- Sell more.
- Drive less.
- Waste less time.
- Learn what works.
- Make tomorrow's route smarter.
