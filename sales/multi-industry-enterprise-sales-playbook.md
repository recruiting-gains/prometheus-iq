# Multi-Industry Enterprise Sales Playbook

Purpose: give the Founder one repeatable enterprise sales motion for every supported Prometheus Route IQ Operating Profile.

Prometheus Route IQ should be sold as the AI operating system for outside sales. The Founder should not rebuild the sales process for each industry. The Founder should select the customer Operating Profile, translate the language, and run the same enterprise motion: qualify field pain, prove pilot fit, run a controlled pilot, measure operating outcomes, and expand from evidence.

## Sales Boundary

This playbook is Sales-owned. It does not modify or authorize changes to Companion, Website, CRM runtime, Dashboard, Infrastructure, Mobile, or Intelligence Engine.

Sales may use this playbook to guide discovery, demos, pilot proposals, executive conversations, pricing context, objections, expansion planning, and account qualification.

## Universal Sales Framework

These elements never change between industries.

### Territory Intelligence

Every outside-sales customer needs to answer:

- Where should reps go?
- Which territories, accounts, locations, routes, or neighborhoods are worth field time?
- Which areas are producing outcomes?
- Which areas should be revisited, deprioritized, or expanded?

Industry language changes. The need for territory intelligence does not.

### Field Accountability

Every manager needs trustworthy evidence of intentional field work:

- What happened?
- Who was active?
- Which visits mattered?
- Which field activities created outcomes?
- Which reps need coaching?

Prometheus should be positioned as proof without surveillance: intentional activity verification, not background tracking.

### Route Optimization

Every field team loses time to poor sequencing, weak territory decisions, repeated dead zones, or disconnected field planning.

Prometheus should connect route decisions to outcomes, not just directions. Route optimization means better field productivity, not just shorter drive time.

### Activity Verification

Every pilot should define what verification means:

- Visit logged.
- Location or account confirmed where appropriate.
- Outcome captured.
- Follow-up captured.
- Manager can review evidence.

Verification is always scoped by the pilot. It should never become uncontrolled surveillance.

### AI Recommendations

Every profile should explain AI as decision support:

- Prometheus recommends where to focus.
- Prometheus explains why a recommendation exists.
- Humans remain in control.
- Weak evidence stays cautious.
- Customer-specific evidence improves future direction.

Do not expose formulas, proprietary weights, or internal scoring logic.

### Manager Visibility

Every buyer should understand the manager value:

- Better daily or weekly review.
- Cleaner coaching conversations.
- Less reliance on memory and screenshots.
- Better understanding of field-to-outcome conversion.
- Clearer decisions about where to send reps next.

### CRM Integration

CRM positioning never changes:

- Prometheus does not replace CRM.
- Prometheus improves the field work that creates CRM-worthy opportunities.
- CRM integration can be discussed later when the pilot proves field value.
- Do not require integration for the first pilot unless the buyer's risk rules demand it.

## What Changes By Industry

Industry-specific language changes:

- Buyer titles.
- Field role names.
- Target names.
- Success outcomes.
- Objections.
- ROI units.
- Pilot scorecard labels.
- Expansion path.

The sales process does not change.

## Repeatable Founder Sales Motion

### Step 1: Select Operating Profile

Choose the closest profile before the first call:

- Fitness: clubs, memberships, tours, referrals, local outreach.
- Roofing: inspections, estimates, contracts, canvassing, storm response.
- Security: site surveys, quotes, contracts, residential or commercial assessments.
- Medical: provider visits, appointments, referrals, agreements.
- Insurance: appointments, quotes, policies, referrals.
- Solar: canvassing, site surveys, proposals, contracts.
- Home Services: estimates, booked jobs, referrals, service territories.
- General Outside Sales: qualified opportunities, appointments, contracts, sales.

If the company does not fit any profile, use General Outside Sales until Research or Intelligence validates a new profile.

### Step 2: Diagnose Field Motion

Ask:

- Who goes into the field?
- Where do they go?
- How do they decide where to go?
- What outcome should each field day create?
- What happens before CRM sees anything?

### Step 3: Identify Manager Pain

Ask:

- What can managers not see clearly today?
- What reports are unreliable?
- What activities are hard to verify?
- Where does follow-up break?
- Which field decisions are still based on guessing?

### Step 4: Build Value Hypothesis

Use:

`If Prometheus helps [team] improve [field behavior], then [manager/buyer] gains [measurable outcome].`

Examples:

- Roofing: If Prometheus helps canvassers focus better territory and log inspection outcomes, the sales manager gets more reliable inspection and estimate pipeline.
- Medical: If Prometheus helps reps track provider visits and referrals, leadership gets clearer referral-source coverage.
- Solar: If Prometheus helps canvassers identify better neighborhoods and follow-ups, managers get higher-quality consultations and proposals.

### Step 5: Qualify Pilot

Pilot must have:

- Operating Profile.
- Sponsor.
- Operating owner.
- Users.
- Territory or location scope.
- Approved outcomes.
- Data boundaries.
- Weekly review.
- Paid rollout path.

### Step 6: Demo The Operating Loop

Demo sequence:

1. Choose Operating Profile language.
2. Show field direction.
3. Show visit/outcome capture.
4. Show manager visibility.
5. Show success scorecard.
6. Propose pilot scope.

Do not lead with feature inventory.

### Step 7: Close Pilot

Close for a controlled pilot:

`The right next step is not a full rollout. It is a controlled pilot with approved users, profile-specific success metrics, weekly review, and a final decision on stop, extend, expand, or paid deployment.`

### Step 8: Convert Evidence

After pilot:

- If adoption and outcomes are strong: propose paid deployment.
- If adoption is strong but outcomes need more evidence: extend pilot with tighter metrics.
- If adoption is weak: diagnose workflow, manager ownership, or fit.
- If field motion is not real: disqualify.

## Operating Profile Playbooks

## Fitness

### Buyer Personas

- Owner or COO: cares about membership growth, local market execution, and club-level performance.
- Regional manager: cares about consistency across clubs and market visibility.
- Sales manager: cares about tours, trials, referrals, follow-up, and membership conversion.
- Club manager: cares about local outreach discipline and field accountability.

### Discovery Questions

- How does the team generate memberships outside the club?
- How are local outreach locations chosen?
- What counts as a qualified local outreach result?
- How are tours, trials, referrals, and memberships tracked today?
- Which managers review field activity weekly?
- What does CRM fail to show before a prospect becomes a lead?

### Business Pain Points

- Local outreach depends on rep memory.
- Managers cannot see which locations produce.
- Tours and referrals are not consistently tied to field activity.
- Reps revisit weak locations.
- Follow-up after field conversations is inconsistent.

### ROI Framework

ROI unit: membership opportunity, tour, trial, referral, or membership sold.

Value equation:

`incremental memberships + improved tour/referral flow + time saved from better route focus - pilot cost`

### Success Metrics

- Field visits logged.
- Managers reached.
- Tours or trials booked.
- Referrals created.
- Memberships sold.
- Follow-ups completed.
- Productive location categories.

### Pilot Structure

- 14 to 30 days.
- One club, district, or local outreach team.
- 3 to 8 users.
- Weekly manager review.
- Final readout comparing visits, leads, tours, referrals, and memberships.

### Objection Handling

- "Fitness is local relationship selling." Response: Prometheus helps reps focus relationship work on locations that produce.
- "We already use CRM." Response: Prometheus improves the local outreach activity before CRM entries exist.
- "We do not want to overburden reps." Response: pilot only the minimum fields needed to connect field visits to outcomes.

### Closing Strategy

Close on a controlled local outreach pilot:

`Let us prove whether Prometheus creates clearer LSM visibility and better membership opportunity flow before discussing market rollout.`

### Expansion Strategy

Club -> district -> market -> region -> national sales operating layer.

## Roofing

### Buyer Personas

- Owner: cares about canvassing ROI, inspections, estimates, contracts, and branch growth.
- Sales manager: cares about inspection pipeline, estimates, follow-up, and rep performance.
- Canvassing manager: cares about doors, territory coverage, callbacks, and accountability.
- Operations manager: cares about inspection and estimate flow before production load.

### Discovery Questions

- How do reps choose neighborhoods or storm areas?
- What counts as a qualified inspection?
- Where do opportunities drop between door, inspection, estimate, and contract?
- How do managers verify canvasser activity?
- Which territories produce the best jobs?
- What would make a 30-day pilot worth expanding?

### Business Pain Points

- Storm response creates chaotic territory coverage.
- Reps revisit weak areas and miss stronger ones.
- Inspection and estimate quality is hard to compare.
- Canvasser accountability depends on manual proof.
- Follow-up after estimates is inconsistent.

### ROI Framework

ROI unit: inspection, estimate, signed contract, or contract value influenced.

Value equation:

`incremental inspections x estimate conversion x contract value - canvassing waste - pilot cost`

### Success Metrics

- Doors or visits logged.
- Decision makers reached.
- Inspections booked.
- Estimates sent.
- Signed contracts.
- Follow-ups completed.
- Productive neighborhoods.
- Manager confidence in canvasser reporting.

### Pilot Structure

- 14 to 30 days.
- One canvassing pod, storm territory, branch, or neighborhood campaign.
- 3 to 8 field users.
- Weekly manager review.
- Final readout on territory productivity, inspections, estimates, and contracts.

### Objection Handling

- "We already use a canvassing app." Response: Prometheus focuses on which field activity produces inspections, estimates, and contracts.
- "Storm work changes too fast." Response: Prometheus helps managers adjust territory learning faster.
- "We only care about signed contracts." Response: inspections and estimates are the leading indicators that show whether field work is creating contract opportunity.

### Closing Strategy

Close on territory intelligence:

`Let us test one territory or canvassing team and measure whether Prometheus improves inspection flow, estimate follow-up, and manager visibility.`

### Expansion Strategy

Canvassing pod -> branch -> storm team -> market -> multi-branch deployment.

- VP sales or sales manager: cares about appointments, quotes, contracts, and rep coaching.
- Branch manager: cares about local territory execution.
- Commercial sales leader: cares about property type focus and account coverage.

### Discovery Questions

- Is the field motion residential, commercial, or mixed?
- What field outcome matters most: site survey, quote, install, monitoring contract, or referral?
- How are territories assigned?
- How do managers verify useful visits?
- Which property types produce best?
- Where does follow-up break after interest?

### Business Pain Points

- Reps spend time in low-intent areas.
- Site surveys are not consistently tracked.
- Residential and commercial motions get mixed.
- Managers cannot see which property categories produce.
- Follow-up after quotes is inconsistent.

### ROI Framework

ROI unit: site survey, quote, contract, install, or recurring monitoring value.

Value equation:

`incremental site surveys + quote conversion + recurring contract value + time saved - pilot cost`

### Success Metrics

- Sites visited.
- Decision makers reached.
- Site surveys booked.
- Quotes sent.
- Contracts signed.
- Follow-ups completed.
- Productive property types.

### Pilot Structure

- 30 days.
- One residential canvassing team or commercial prospecting team.
- 3 to 8 users.
- Separate residential and commercial metrics.
- Weekly review by sales or branch manager.

### Objection Handling

- "Security is trust-based." Response: Prometheus helps reps focus relationship time where assessment opportunities are most likely.
- "We have appointment software." Response: Prometheus improves the field work that creates appointments.
- "Residential and commercial are different." Response: choose one pilot motion first.

### Closing Strategy

Close on site-assessment productivity:

`Let us pilot one field team and measure whether Prometheus improves site surveys, quote follow-up, and territory focus.`

### Expansion Strategy

Team -> branch -> residential/commercial channel -> market -> enterprise account motion.

## Medical

### Buyer Personas

- CEO or COO: cares about growth, referral sources, and compliant execution.
- VP business development: cares about provider coverage and referral relationship quality.
- Director of physician relations: cares about practice visits and follow-up.
- Regional director: cares about territory consistency and market expansion.

### Discovery Questions

- Who are the field reps visiting: providers, clinics, hospitals, referral sources, or community partners?
- What data can and cannot be entered?
- What counts as a qualified provider opportunity?
- How is referral-source activity reviewed?
- Which relationships are undercovered?
- Who approves compliance-safe pilot boundaries?

### Business Pain Points

- Referral-source activity is hard to compare.
- Reps rely on memory and relationship anecdotes.
- Leadership cannot see provider coverage clearly.
- Compliance constraints make generic tools risky.
- Follow-up after visits is inconsistent.

### ROI Framework

ROI unit: provider appointment, referral-source movement, qualified referral conversation, or agreement.

Value equation:

`improved referral-source coverage + qualified appointments/referrals + follow-up discipline - pilot cost`

Use customer-provided economics only. Do not estimate patient value without approval.

### Success Metrics

- Practices or referral sources visited.
- Providers reached.
- Appointments booked.
- Referrals created.
- Follow-ups completed.
- Relationship-stage movement.
- Compliance-safe usage.

### Pilot Structure

- 30 days.
- One market, service line, or referral-source team.
- 2 to 5 users.
- Approved non-patient activity only.
- Weekly review with business development manager.

### Objection Handling

- "We have compliance concerns." Response: define approved activity and prohibited data before launch.
- "Our reps know their providers." Response: Prometheus makes coverage visible enough to coach and scale.
- "CRM already tracks accounts." Response: Prometheus improves daily field direction and visit-level learning.

### Closing Strategy

Close on compliant referral-source visibility:

`Let us run a controlled, non-patient-data pilot to see whether Prometheus improves provider coverage and field follow-up.`

### Expansion Strategy

Service line -> market -> region -> enterprise referral-source operating layer.

### Success Metrics

- Decision makers reached.
- Quotes created.
- Policies bound.
- Referrals created.
- Follow-ups completed.

### Pilot Structure

- Owner or CEO: cares about appointment volume, acquisition cost, and market expansion.
- VP sales: cares about canvasser productivity and closeable consultations.
- Canvassing manager: cares about neighborhoods, doors, callbacks, and accountability.

- What qualifies a homeowner for a consultation or survey?
- Where do opportunities drop: door, callback, consultation, proposal, financing, or contract?
- How do managers verify canvassing activity?
- What neighborhood signals matter?
- What would make a pilot worth expanding?

### Business Pain Points

- Canvassers spend time in low-fit neighborhoods.
- Door results and callbacks are inconsistently tracked.
- Managers lack reliable field activity quality.
- High-performing territory patterns stay informal.
- New reps ramp slowly.

### ROI Framework

ROI unit: qualified consultation, site survey, proposal, or signed contract.

Value equation:

`incremental consultations x show rate x proposal/contract conversion + reduced canvassing waste - pilot cost`

### Success Metrics

- Doors or visits logged.
- Homeowners reached.
- Site surveys booked.
- Proposals sent.
- Contracts signed.
- Callbacks completed.
- Productive neighborhoods.

### Pilot Structure

- 14 to 30 days.
- One canvassing team or neighborhood campaign.
- 3 to 8 users.
- Track territory, appointments, proposals, and follow-up.
- Weekly review with canvassing manager.

### Objection Handling

- "Solar canvassing is already crowded with tools." Response: Prometheus competes on explainable field learning and territory productivity, not basic canvassing maps.
- "Policy and financing change demand." Response: pilot focuses on controllable field execution and qualified consultations.
- "Door knocking is variable." Response: Prometheus helps identify the variables worth repeating.

### Closing Strategy

Close on consultation productivity:

`Let us test whether Prometheus improves neighborhood focus, qualified consultations, and proposal follow-up before discussing broader rollout.`

### Expansion Strategy

Canvassing pod -> market -> regional canvassing team -> multi-market solar acquisition layer.

## Home Services

### Buyer Personas

- Owner or general manager: cares about booked jobs, estimates, and local market growth.
- Sales manager: cares about estimates, close rate, and follow-up.
- Service manager: cares about demand quality and operational handoff.
- Branch manager: cares about local territory execution.

### Discovery Questions

- Which service line is the first wedge: HVAC, pest, plumbing, cleaning, landscaping, restoration, or another service?
- What field outcome matters most: estimate, booked job, contract, referral, or follow-up?
- How are neighborhoods, accounts, or service areas selected?
- What activities happen before the job is booked?
- What does the current system fail to show?
- Which manager would review pilot data weekly?

### Business Pain Points

- Home Services is broad and can become unfocused.
- Sales motions vary between estimates, service calls, maintenance plans, and replacement opportunities.
- Existing field-service systems may own dispatch but not outside-sales intelligence.
- Follow-up after estimates is inconsistent.
- Territory learning is rarely formalized.

### ROI Framework

ROI unit: estimate, booked job, recurring plan, referral, or contract.

Value equation:

`incremental estimates + booked jobs + follow-up recovery + reduced wasted territory time - pilot cost`

### Success Metrics

- Homes or accounts visited.
- Decision makers reached.
- Estimates created.
- Jobs booked.
- Referrals created.
- Follow-ups completed.
- Productive service areas.

### Pilot Structure

- 30 days.
- One service line only.
- One branch, territory, or sales team.
- 3 to 8 users.
- Weekly manager review.

### Objection Handling

- "Home services is too broad." Response: select one service line and one field outcome for the pilot.
- "We already use field-service software." Response: Prometheus does not replace dispatch or job management; it improves field sales and estimate intelligence.
- "Our technicians create opportunities." Response: pilot should focus only on the sales/outreach workflow the manager can control.

### Closing Strategy

Close on one service-line wedge:

`Let us pick one field outcome, one team, and one territory so the pilot proves value without becoming a generic operations project.`

### Expansion Strategy

Service line -> branch -> market -> adjacent service line -> multi-branch deployment.

Team -> territory -> market -> region -> dedicated Operating Profile if repeated evidence supports it.

I recommend a controlled pilot using the [Operating Profile] profile with [users] in [territory/team] for [duration]. ## Duplicate Prevention Rule

Do not create a separate sales process for a new industry. Start with this playbook, choose an existing Operating Profile, and create a new vertical package only after repeated discovery shows that General Outside Sales is insufficient.
