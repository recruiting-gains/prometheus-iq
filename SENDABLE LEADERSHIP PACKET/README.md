## How To Use This Package

Use this package only after speaking with Chris or after Chris asks for materials.

Recommended approach:

1. Discuss the pilot verbally first.
2. Ask Chris whether a short packet would help before Dallas.
3. If he says yes, send the cover sheet first or attach the three-document packet.
4. Do not overload leadership with internal strategy, source code, pricing, patents, or future roadmap.
5. Keep the ask narrow: a controlled 14-day private pilot with 3 approved users, consent, weekly review, and a final private report.
