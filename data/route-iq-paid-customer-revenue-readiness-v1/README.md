# Route IQ Paid-Customer Revenue Readiness Data v1

Prometheus Data owns this isolated, fictional commercial rehearsal contract.

The fixture is company- and workspace-bound, remains nonproduction, and preserves
immutable Draft and Validated evidence without admitting either state to customer
activation. It pins historical and current pricing and commercial-term versions,
records zero production writes, and defines auditable quarantine and removal
evidence.

Retention is a governed Data operation. Export and deletion require an authorized
customer request; deletion remains a Data-owned execution. None of these operations
is authorized in production by this contract.

The fixture contains no real customer, representative, CRM, billing-provider, or
live provider data. It cannot be used as a canonical production record.
