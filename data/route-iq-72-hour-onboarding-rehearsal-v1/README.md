# Route IQ 72-Hour Onboarding Rehearsal v1

This Data-owned package is deterministic synthetic evidence for one onboarding
rehearsal. It is not a customer roster, production admission, provider refresh,
or canonical Route IQ business manifest.

The package proves that a new supported company can supply:

- an approved rehearsal roster with explicit territory and postal-code scope;
- business-hours freshness, provenance, and fail-closed eligibility metadata;
- a rehearsal-only manifest registry with immutable source hashes; and
- deterministic in-memory runtime assets without modifying deploy mirrors.

Every artifact is classified
`SYNTHETIC_NONCANONICAL_REHEARSAL_ONLY`, denies production use and canonical
manifest admission, and remains outside
`route-iq-workspace-business-artifact-manifest-registry-v1.json`.

The validator also pins the canonical production Data baseline at active `0`,
reserve `0`, and quarantine `398`. It fails if any canonical pool or manifest
changes while rehearsal assets are loaded or generated.
