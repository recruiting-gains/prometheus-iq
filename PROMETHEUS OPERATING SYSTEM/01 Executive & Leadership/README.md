# 01 Executive & Leadership

## Purpose

This folder is the executive decision center for Prometheus. It contains the materials used to explain Prometheus IQ to leadership, request pilot approval, brief operators, and keep executive communication focused.

## Included Documents

- `docs/prometheus-pilot-approval-cover-sheet.md`
- `docs/executive-briefing-packet-chris-dallas.md`
- `SENDABLE LEADERSHIP PACKET/`
- `output/pdf/Prometheus_IQ_Sendable_Leadership_Packet.pdf`
- `PROMETHEUS EXECUTIVE PACKAGE/`
- `PROMETHEUS EXECUTIVE PACKAGE/RECOMMENDED NEXT STEP.md`

## When To Use Each Document

- Pilot Approval Cover Sheet: Use when an executive has less than 60 seconds and needs to understand the request quickly.
- Executive Briefing Packet: Use when leadership wants more context on the business problem, proposed pilot, safeguards, and success metrics.
- Sendable Leadership Packet: Use only when Chris, Dallas leadership, COO, President, HR, or Operations requests material for initial review.
- Sendable PDF: Use when a polished attachment is needed instead of Markdown or code-style files.
- Executive Package: Use internally to understand all Prometheus leadership materials.
- Recommended Next Step: Use before deciding what to send, what to hold back, and what to discuss live first.
