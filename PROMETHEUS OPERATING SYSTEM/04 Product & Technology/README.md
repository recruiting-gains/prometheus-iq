# 04 Product & Technology

## Purpose

This folder is the product and engineering control center. It helps future builders understand what Prometheus IQ is, where the app lives, what has been built, and what should be protected.

## When To Use Each Document Or Asset

- Product Vision: Use to understand the long-term product direction.
- Prometheus Notes: Use to understand the broader product concept and founder thinking.
- Cloud Beta Cost and Response Plan: Use when planning accounts, cloud storage, synchronization, backups, and beta costs.
- Public Site Cloudflare Readiness: Use before deploying the public marketing website.
- Website Cinematic Prompts: Use when continuing the cinematic homepage direction.
- Root README: Use for basic project orientation.
- App Source Files: Use for app development and product changes.
- Public Website Files: Use for homepage and marketing site work.
- Deployment Folder: Use when preparing files for Cloudflare deployment.
- Icons and Public Assets: Use for brand visuals and app/site assets.

## Guardrail

Product documents may describe outcomes and user flows. Public-facing documents should not reveal source code, proprietary scoring, internal prompts, or protected intelligence logic.
