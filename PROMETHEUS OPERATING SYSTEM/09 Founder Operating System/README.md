# 09 Founder Operating System

## Purpose

This folder keeps the founder strong, focused, and repeatable. It protects the company from becoming dependent on scattered memory, late-night emotion, or burnout.

## Included Documents

- `docs/prometheus-founder-operating-system.md`
- `docs/prometheus-origin-story-development-history.md`
- `docs/founder-master-notes.md`
- `docs/founder-pressure-test-log.md`
- `docs/investor-readiness-plan.md`
- `docs/today-roadmap-october-1.md`
- `docs/daily-plan-2026-06-19.md`
- `PROMETHEUS OPERATING SYSTEM/09 Founder Operating System/Daily Progress Log.md`

## When To Use Each Document

- Founder Operating System: Use weekly to balance Prometheus, AI school, marriage, health, and customer support.
- Origin Story & Development History: Use when explaining how Prometheus was built, onboarding future team members, preparing founder story materials, or preserving company memory.
- Founder Master Notes: Use as the larger founder knowledge base.
- Founder Pressure Test Log: Use for VC-style practice and investor readiness.
- Investor Readiness Plan: Use when preparing for future investor conversations.
- October 1 Roadmap: Use for long-range planning and milestone tracking.
- Daily Plan: Use as a sample of daily execution discipline.
- Daily Progress Log: Use after meaningful work sessions to preserve what changed, what moved forward, deployment status, GitHub status, and the next recommended move.
